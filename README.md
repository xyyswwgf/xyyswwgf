## Agent 项目方向

我正在把“案例推送”整理成一个完整 Agent 项目：

- 搭建：Node.js 项目结构、环境变量、数据源配置、定时任务
- Agent 设计：采集器、筛选器、总结器、报告生成器、推送器
- 推送方式：钉钉机器人、飞书机器人、Webhook 扩展
- 产出：每日/每周案例报告、Markdown 归档、消息卡片推送

## 自动化网站方向

- 汇率自动化：定时更新主流货币汇率，生成轻量查询页面和趋势数据
- 数据看板：把 CSV、API 和数据库数据转成可视化面板
- 信息聚合：自动抓取、清洗、总结并推送到工作流工具
- 小工具站：围绕实际问题做可快速访问的页面工具
