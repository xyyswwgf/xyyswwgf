## 从数据到行动

```mermaid
flowchart LR
    A[信息采集] --> B[筛选与校验]
    B --> C[分析与总结]
    C --> D[报告与可视化]
    D --> E[团队消息推送]
```

- **Agent 与分析**：结构化输入输出、可追溯来源、模型响应校验。
- **自动化工具**：业务规则配置、数据查询、轻量看板、CLI 和定时任务。
- **工程实践**：环境变量管理、可配置工作流与可复现的本地运行方式。
